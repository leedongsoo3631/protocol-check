공유 서버 만들기

우리 부서·기관 전용 공유 서버를 구글 계정 하나로 무료로 만듭니다. 명단·체크 기록·채팅은 만든 사람의 구글 드라이브에 있는 스프레드시트에만 저장됩니다.

10분컴퓨터 크롬 기준
무료구글 계정만 있으면 됨
내 드라이브데이터 저장 위치

  1. Apps Script 새 프로젝트 열기

    크롬에서 구글 계정으로 로그인한 상태로 엽니다. 위쪽 '제목 없는 프로젝트'를 눌러 의전 체크 서버로 이름을 바꿔 두면 찾기 쉽습니다.

    script.google.com/create 열기 ↗

  2. 서버 코드 붙여넣기

    편집기에 있는 내용을 모두 지우고(Ctrl+A → Delete) 아래 버튼으로 복사한 코드를 붙여넣습니다(Ctrl+V).

    코드 보기 ↗

  3. 편집 비밀번호 정하기

    코드 맨 위 const EDIT_PIN = '0000'; 에서 0000을 원하는 숫자로 바꾸고 저장(Ctrl+S)합니다. 명단·좌석·일정을 고칠 때 쓰는 비밀번호입니다.

  4. 준비 실행 (권한 허용)

    위쪽 함수 목록에서 setup을 고르고 ▶ 실행을 누릅니다.

    권한 검토 → 내 계정 선택 → 고급 → '의전 체크 서버(으)로 이동(안전하지 않음)' → 허용

    '안전하지 않음'은 구글이 심사하지 않은 개인 코드라는 뜻입니다. 이 코드는 내 드라이브의 시트 하나만 만들고 씁니다.

  5. 웹 앱으로 배포

    배포 → 새 배포 → 톱니바퀴 ⚙ → 웹 앱

    다음 사용자 인증 정보로 실행: 나 · 액세스 권한이 있는 사용자: 모든 사용자 → 배포

    나온 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사합니다.

  6. 앱에 연결

    의전 체크 앱 ☰ 메뉴 → 내 공유 서버 만들기 → 6번 칸에 붙여넣고 연결 확인하고 저장을 누릅니다. 설정의 '공유 서버 주소' 칸에 넣어도 됩니다.

  7. 담당자 초대

    앱 ☰ 메뉴 → 담당자 초대하기로 복사된 문구를 카톡방에 보내세요. 받은 사람은 그 문구를 통째로 설정의 서버 주소 칸에 붙여넣으면 바로 연결됩니다.

코드를 업데이트할 때 — 새 코드를 붙여넣고 저장한 뒤 배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포. 주소가 바뀌지 않아 담당자들은 아무것도 할 필요가 없습니다.
