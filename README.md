# 의전 체크

행사 의전 담당자가 참석 인사(사진·이름·직위)의 도착을 체크하고, 현황을 사진으로 만들어 카카오톡으로 보내는 안드로이드 앱입니다. 구글 시트를 연결하면 여러 담당자가 같은 현황을 실시간으로 봅니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `web/index.html` | 보드 화면. **보드를 고치면 이 파일만 바꾸면 됩니다** (앱 빌드 때 자동으로 앱 안에 들어감) |
| `app/` | 안드로이드 앱 (보드 실행, 사진 선택·공유·갤러리 저장 연결) |
| `server/Code.gs`, `server/Index.html` | 구글 시트 공유 서버 (Apps Script에 붙여넣기) |
| `docs/privacy.html` | 개인정보처리방침 (GitHub Pages로 공개) |
| `docs/server-setup.html` | 다른 부서·기관이 자기 공유 서버를 만드는 안내 페이지 |
| `store/` | 플레이스토어 등록 준비물 — 아이콘, 그래픽 이미지, 스크린샷 6장, 등록정보 문구(`listing_ko.md`), 등록 순서·정책 답변표(`PLAY_GUIDE.md`) |
| `.github/workflows/build.yml` | 자동 빌드. `main`에 올리면 설치 파일이 만들어져 **Releases**에 올라감 |

## 빌드 결과 받기

저장소 첫 화면 오른쪽 **Releases** → 최신 버전

- `uijeon-check_v*.apk` — 휴대폰에 바로 설치
- `uijeon-check_playstore_*.aab` — Google Play Console에 업로드

## 서명키

플레이스토어용 파일은 저장소 **Settings → Secrets and variables → Actions** 에 저장된 서명키로 서명합니다.
`KEYSTORE_BASE64`(서명키 파일 내용), `KEYSTORE_PASSWORD`(비밀번호) 두 개 — 서명키 파일(upload.jks)과 비밀번호는 저장소에 올리지 말고 따로 보관하세요.

## 주요 기능

- 카드 눌러 도착 체크(실시간 공유, 인터넷 끊김 시 보관 후 자동 재전송), 이름 검색
- 좌석배치도(세로·가로·통로, 자리별 이름, 도착 시 초록색), 좌석표 이미지
- 현황 보내기(사진·텍스트), 행사 결과 보고(도착률·순서·시간대 분포, 보고 이미지)
- 행사 일정·메모·식순 사진(확대 보기), 담당자 채팅(접속 중 표시), 담당자 위치 지도(V-World)
- 새 행사 시작(명단 유지, 기록 정리), 처음 사용 안내, 내 공유 서버 만들기 안내, 담당자 초대 문구
- 알림(진동·소리, 화면 꺼짐 시 백그라운드 알림)
